Cortext 0.3 is out! It's mostly a maintenance release, but a satisfying one: we moved to WordPress 7.1, laid the groundwork for what comes next (archiving and a Windows app), and fixed a handful of annoyances you may have run into along the way.

WordPress 7.1

Cortext now requires WordPress 7.1, so if your site is still on 7.0, update WordPress first and Cortext after. The browser demo and the Mac app already ship with 7.1; you're all set there.

Testing the upgrade also surfaced a couple of saving issues; both are fixed now. Cortext waits until your latest edit is stored before closing or switching a page, so what you see as saved is indeed what's saved.

Ready for translation

This is one we've been looking forward to: every label in the interface is now ready to be translated on WordPress.org (plurals and formula suggestions included). Note that formulas you've already written keep working in any language.

No translations have shipped yet, so if you'd like to see Cortext in your language, feel free to jump into the translation project; we'd love the help!

Smaller fixes

  • The sidebar picks up a document's new title or icon right away.
  • Opening a document from the sidebar moves keyboard focus into it.
  • Collection menus no longer hide behind the block toolbar or overlap each other.
  • Collection pagination is aligned again.
  • Mentions keep their icons when you move the cursor across them.

Groundwork for what comes next

Some of the best parts of 0.3 aren't visible yet. Cortext can already archive documents on the server (archived content stays read-only), and the controls to do it yourself are coming very soon. The desktop app also builds on Windows now; there's no Windows download yet, but it's on its way.

The full list, with links to every merged change, is in the Cortext 0.3.0 release notes.

Still a beta

The data model and interface are still settling, so things may move between releases. The release notes explain what changed each time, and the download page has the current requirements and limits.

If something breaks or feels off, we'd love to hear about it on GitHub 🙂
